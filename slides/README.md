# Run-length encoding in C

[Open the PowerPoint](rle-slides.pptx). The ten-slide talk is paced for about six minutes. Slide 3 gives the class time to make a prediction before slide 4 reveals the result. Short explanations appear alongside each example, with optional prompts in the speaker notes.

| 4 | 1:45 | Count the runs to explain the 4-byte and 16-byte results. |
| 5 | 2:20 | Follow a row of dots and hashes in the 400-byte picture. |
| 6 | 3:05 | Explain why the 43-byte sentence doubles. |

| 10 | 5:30 | Reflect on the difference between typed digits and stored bytes, then take questions. |
